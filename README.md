# FDE Workflow

中文 FDE 项目工作流 skill，当前为 `0.1.0-draft` 试用版。

帮助使用者从机会筛选、客户沟通、可行性与报价，推进到演示、软件开发、验收、回款和售后。支持从零定制、已有产品实施，以及接手已经在使用的项目；AI 根据当前成果、客户条件与使用者能力调整指导。

## 开始使用

试用时把整个 `skills/fde-workflow/` 目录交给能读写文件、运行代码的 AI 编程工具。在新会话中明确指定入口文件，例如：

```text
请读取我提供的 fde-workflow/SKILL.md，按其中需要选择参考文件。
我是第一次做客户项目。先帮助我判断当前处于哪一步、下一步该做什么。
客户材料与项目产物放在我指定的独立项目目录。
```

在本仓库中，入口是 [skills/fde-workflow/SKILL.md](skills/fde-workflow/SKILL.md)。若工具支持原生 skill 安装，将完整目录放入该工具配置的技能目录；完成注册后可用 `$fde-workflow` 调用。各工具的发现和安装方式需以其当前说明为准，本版未自动修改全局设置。

技能目录包含入口和按需参考／模板，符合 [OpenAI 官方技能说明](https://developers.openai.com/plugins/concepts/skills) 描述的目录形态。首版不依赖独立 FDEOps CLI；客户软件开发所需工具按具体项目检查。跨工具的自动发现和加载仍需分别验证。

## 可以怎样提问

```text
我刚收到一个客户想法，帮我准备首次访谈，并判断值不值得继续投入。
```

```text
我有现成产品，客户要求接入旧系统，但数据很乱。先评估条件和费用，不要直接承诺总价。
```

```text
系统已经有人使用，但还没谈价格。复用现有成果，帮我梳理付费方案和证据缺口。
```

```text
本轮需求和验收已经确认。检查当前仓库后，实现第一个可运行增量，并记录实际验证结果。
```

首次不需要一次填满所有模板。AI 应给出当前可执行动作和产物，重要未知影响哪个步骤，就处理哪个步骤。

## 文件与边界

- `skills/fde-workflow/`：可单独交给 AI 的 skill 包；来源声明和上游许可证随目录保留。
- `docs/`：设计与合成纸面演练，供维护者和使用者审阅，不是默认加载的全部上下文。
- `tests/`：维护者使用的检查与合成行为场景，不是客户项目产物。
- `.work/`：本地缓存及隔离演练产物，排除在发布材料之外。

客户代码、业务文档、项目记忆、内部测算及凭据存放在独立项目位置，不随 skill 公开。当前记录是普通文件，不提供自动脱敏或权限隔离。
